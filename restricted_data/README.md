# Qatar data boundary

The Qatar PV source telemetry used in the manuscript is confidential / owner-controlled and is not redistributed in this repository.

A reproducibility package may expose only disclosure-safe objects such as:
- coded channel schema;
- chronological split definitions;
- mask registries;
- model/configuration files;
- derived aggregate and mask-level metrics approved for release;
- source-file hashes and provenance records when permitted.

No synthetic replacement should be presented as the original Qatar measurements.
